## комментарий в одну строку

Содержимое после `//` является комментарием до конца строки.

```wave
var count: i32 = 10;
// 현재 요청 수
```

## блокировать аннотацию

Обработайте пробел между `/*` и `*/` как комментарий к блоку.

```wave
/* 여러 줄에 걸친
   설명을 작성할 수 있습니다. */
```

Вы можете вкладывать другие комментарии блока в комментарий блока.

```wave
/* 바깥 주석
   /* 안쪽 주석 */
다시 바깥 주석
*/
```

## Строки и знаки комментариев

`//`, `/*` и `*/` внутри строковых и символьных литералов представляют собой строковое содержимое и не рассматриваются как начало или конец комментария.

```wave
var text: str = "https://wave-lang.dev";
```

## Незакрытые блочные комментарии

Если не закрыть комментарий блока с помощью `*/`, будет выставлен диагноз `E1002 UnterminatedComment`.

Даже при временном отключении длинных блоков убедитесь, что глубина вложенности правильная.
