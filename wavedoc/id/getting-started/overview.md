## Pelajari Wave dengan panduan ini

Belajar menulis kode sumber Wave, kompilasi dan jalankan, dan periksa hasilnya. Jika Anda baru mengenal pemrograman, ikuti urutan di bawah ini. Jika Anda menguasai bahasa lain, jalankan contoh setiap bab dan bandingkan aturan serta batasannya dengan apa yang sudah Anda ketahui.

## Praktekkan pengetahuan Anda

Setelah bab inti, buatlah [kalkulator input](/docs/id/practice/input-calculator), [pembaca file](/docs/id/practice/file-reader), [pesan biner](/docs/id/practice/binary-message), dan [klien TCP](/docs/id/practice/tcp-client). Uji kasus masukan dan kegagalan yang berhasil di setiap proyek.

## Tiga tab dokumentasi

- **Wave**: Kursus bahasa terpandu dan proyek praktis yang harus diikuti.
- **[Perpustakaan standar](/docs/id/stdlib)**: API setiap modul, nilai pengembalian, kesalahan, aturan kepemilikan, dan persyaratan platform.
- **[Whale](/docs/id/whale)**: Membangun dan menghubungkan, manajemen paket, penggunaan perintah, dan rantai alat tingkat rendah.

Contoh membedakan program lengkap dari cuplikan yang termasuk dalam suatu fungsi. Jalankan perintah `wavec` di terminal dan simpan blok kode `wave` dalam file `.wave`. Input dan output ditampilkan secara terpisah; contoh yang membaca input standar menentukan apa yang harus dimasukkan.

## Ketika Anda terjebak

Gunakan [Pemecahan Masalah](/docs/id/reference/diagnostics) untuk membedakan masalah instalasi, pemeriksaan sumber, penautan, dan eksekusi. Cari aturan bahasa di [referensi cepat sintaksis](/docs/id/reference/syntax-quick-reference), perintah di [referensi kompiler](/docs/id/getting-started/compiler), dan API di [panduan perpustakaan standar](/docs/id/reference/standard-library).
