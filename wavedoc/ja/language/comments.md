## 一行コメント

`//` 後の内容は行末までのコメントです。

```wave
var count: i32 = 10;
// 현재 요청 수
```

## ブロックコメント

`/*`と`*/`の間をブロックコメントとして扱います。

```wave
/* 여러 줄에 걸친
   설명을 작성할 수 있습니다. */
```

ブロックコメント内には、他のブロックコメントを入れ子にすることができます。

```wave
/* 바깥 주석
   /* 안쪽 주석 */
다시 바깥 주석
*/
```

## 文字列とコメント記号

文字列と文字リテラル内の`//`、`/*`、`*/`は文字列の内容であり、コメントの先頭または末尾として扱われません。

```wave
var text: str = "https://wave-lang.dev";
```

## 閉じていないブロックコメント

ブロックコメントを`*/`で閉じないと、`E1002 UnterminatedComment`診断が発生します。

長いブロックを一時的に無効にしても、入れ子の深さが正しいことを確認してください。
